## 规模与风险

- 当前 supported 车身英雄数：24。
- 恰选四名、允许重复、不计顺序：17,550 组。
- 1%比例点：5,151。
- 比例×全车身理论 exact 空间：90,400,050。

曾直接启动全英雄车身 benchmark；运行约5分钟、Node工作集接近1GB仍未完成，因此例行样本保持4名真实确定性 supported 候选的完整35组合。优化器本身仍保留 exact search，没有剪枝或近似；“候选数 × 精确概率状态传播”仍是明确性能瓶颈。发布候选版已将 UI 优化调用放入 Web Worker，长任务不会占用页面主线程，但这不会减少总计算量，也没有更改算法语义。

本轮只改变基础伤害数值与已确认的 next-round 刷新状态演化，不改变候选数量或 exact search 语义。大于5000总兵数的第一个根号现在固定取 `sqrt(5000)`，不能为复现旧 benchmark 伤害而调整 `k`。
